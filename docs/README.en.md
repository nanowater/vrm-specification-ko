# VRM Specification (Korean Translation Project)

[![GitHub Repository](https://img.shields.io/badge/GitHub-vrm--specification-blue?logo=github)](https://github.com/vrm-c/vrm-specification)

This repository and documentation are an **unofficial Korean translation created for personal study purposes**, based on the official VRM Specification documents from [vrm-c/vrm-specification](https://github.com/vrm-c/vrm-specification).

This document is based on the specification of [vrm-specification](https://github.com/vrm-c/vrm-specification) at commit [3942748](https://github.com/vrm-c/vrm-specification/commit/3942748efbc803b258e288e0f6c993c6bb96cebf).
