# VRM Specification (韓国語翻訳プロジェクト)

[![GitHub Repository](https://img.shields.io/badge/GitHub-vrm--specification-blue?logo=github)](https://github.com/vrm-c/vrm-specification)

本リポジトリおよびドキュメントは、[vrm-c/vrm-specification](https://github.com/vrm-c/vrm-specification)の公式VRM仕様（Specification）ドキュメントをもとに、**個人学習目的で作成された非公式の韓国語翻訳版**です。

本ドキュメントは [vrm-specification](https://github.com/vrm-c/vrm-specification) の [3942748](https://github.com/vrm-c/vrm-specification/commit/3942748efbc803b258e288e0f6c993c6bb96cebf) コミット時点の仕様を基準に作成されています。
